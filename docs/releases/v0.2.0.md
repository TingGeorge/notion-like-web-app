## 新功能

- **用配對碼連結新裝置**：新裝置沒有相機（或鏡頭壞了）時，在已連結的裝置按 設定 → 連結新裝置 →「新裝置沒有相機？改用配對碼」，再到新裝置選「沒有相機？用配對碼連結」，輸入 GitHub 帳號和 10 碼配對碼就能連上。加密後的設定只會在你的 GitHub gist 暫放幾分鐘，新裝置取得後立刻刪除。token 需要多開 *Gists: Read and write* 權限（沒開時 app 會說明怎麼加）。
- **圖片縮放與裁切**：拖曳圖片左右兩側即可調整寬度；按圖片右上角的「裁切圖片」可以框選要留下的範圍。在 github.com 上看筆記，大小和裁切結果也一樣（寬度寫成 `<img width>`，裁切會另存一張新圖，原圖仍在 repo，⌘Z 可還原）。

## 修正

- **支援永不過期的 token**：在 GitHub 建立 token 時選了 *No expiration*，設定和「更換 token」時勾選「永不過期」即可，不會再要求填到期日，也不會出現到期提醒。
- 更換 token 後，到期提醒會立刻更新，不必重新整理。

## New

- **Link a device by typing a code**: when the new device has no camera, choose 「新裝置沒有相機？改用配對碼」 on a linked device and type the GitHub account and the 10-character code on the new one. The encrypted setup waits in a gist of your account for a few minutes and is deleted as soon as the new device has it. The token needs *Gists: Read and write*.
- **Resize and crop images**: drag either side of an image to resize it, or crop it with 裁切圖片. github.com shows the same size and crop.

## Fixed

- **Tokens that never expire**: tick 「永不過期」 for a token created with *No expiration*; no date is required and no expiry banner appears.
- After 更換 token, the expiry banner updates without a reload.
